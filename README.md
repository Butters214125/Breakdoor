|---------|-------------|--------|
| 🚀 **Fly** | Fly through the air with adjustable speed | ✅ Stable |
| 💨 **Speed Boost** | 1x-25x walk speed multiplier | ✅ Stable |
| 👁️ **ESP** | See all players through walls with health bars | ✅ Stable |
| 🎁 **Auto-Loot** | Automatically teleport to presents/airdrops | ✅ Stable |

2. Paste into your executor
3. Execute and enjoy!
